《未来战争》当前 AI 策略总览
依据 CoreGeek/src/main/java/com/huawei/strategy 实际代码整理 · 2026-09-20（新战术版）
总调度 DecisionEngine（每回合）
初始化阵营/基地 → 换日重置 LLM 计数(refreshDay) → 记忆已知矿点(recordMines) → 统计武器数(countWeapons) → 昼夜判定 roundNo%130 < 70 为白天，否则夜晚 → 分发策略；occupiedRoles 防止同一角色被重复分配
白天 DayStrategy
工人 WorkerStrategy · 优先级链
  1. 白天第 60 回合起 → 回最近武器旁（夜晚前回炮台御敌）
  2. 围墙血量 <300 且有 WallFixer → 走到墙旁 use 修复（保证围墙血量）
  3. 武器数 <3 → 基地旁 3 个外角位优先建火箭发射台（开局 3 火箭炮）
  4. 有石头 → 按阵营建围墙：面向敌人的一面优先（角+两侧边），其次两侧，后方不建
  5. 升级：武器升级券优先（火箭优先，level1→Voucher1/level2→Voucher2）→ 围墙/基地升级券 → 无券且金币≥100 → 商店买武器升级券1
  6. 背包剩余 ≤5 → 走向小贩，按当前收购价卖最值钱矿
  7. 否则 采集最近矿点（移动到矿旁 → collect）
  8. 无事可做 → 武器商店旁待命
开拓者 PioneerStrategy · 优先级链
  1. 白天第 60 回合起 → 回最近武器旁（夜晚前回基地）
  2. 调用 TaskSolver 专心接任务/交任务（状态机驱动）
  3. 血量 <60 → 用药；没药且金币≥10 → 商店买 Medicine
  4. 未开宝藏且背包有任务用品 → 到任务点 召唤宝藏
  5. 到武器商店采购：补 Medicine / 金币≥45 且空间≥3 → 买任务用品（AcientTablet 等 3 种）备用
  6. 否则 → 任务点旁待命
夜晚 NightStrategy
1. 战斗优先 CombatStrategy（3 火箭齐射）
每座武器：找周围一格内未占用的非建筑角色当操控者（找不到则不攻击）→ 选择目标 → 下发 attack（key=武器ID，controllerId=操控角色）
火箭冷却 cooldown>0 时跳过
2. 角色就位
未被分配指令的工人/开拓者 → 移动到最近武器旁待命；血量低且有药则先用药
战斗目标选择（威胁值 = 基础分 × 当前血量）
加特林 gatling等级=目标数(1/2/3)，按威胁降序取目标，多目标须落在同一 90° 锥形内，距离 ≤ attackRange
电磁炮 railgun单目标，射程内威胁值最大的机器人（能量穿透）
火箭 rocket等级=导弹数(1/2/3)，选机器人最密集的 3×3 区域，落点中心距 ≤2 视为重叠不重复选
目标筛选：优先 targetTeam=己方 的机器人；无则攻击全部可见机器人
自进化任务状态机 TaskSolver
IDLE → 发现可用任务点(isValid && 冷却0) → 移动/接取 acceptTask
→ TASK_ACCEPTED → 构造 prompt 提交 LLM
→ AWAIT_LLM → 收到 llmResp：有代码块→提交沙盒 executeCmd；仅答案→待提交
→ AWAIT_CMD → 收到 lastCmdResult（[exitCode:0] 成功）→ 用输出作答案
→ READY_TO_SUBMIT → 下回合 submitAnswer → SUBMITTED → 回 IDLE
错误 errorCode=1(超时)/2(答案错) → 重置 IDLE
指令合法性预检（避免异常累计出局）
夜晚不下发 build/collect · 白天不下发 attack · 仅工人生成 build/collect/remove · 仅开拓者生成 acceptTask/submitAnswer/summonTreasure · 阵亡角色（不在 roles 列表）不下发指令 · 决策异常兜底返回已生成指令而非空响应
